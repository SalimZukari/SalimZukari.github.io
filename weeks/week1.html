The Network at a Glance

303 characters. But how evenly connected are they?

Every number below is calculated live from the frozen Week 1 dataset — nothing here is hard-coded. These are the headline statistics of the Marvel Wikipedia character network.

How is this calculated?

Average degree. Every undirected edge contributes 2 to the total degree because it touches two nodes. So average degree = 2 × edges / nodes.

Density. Density tells us how many of the possible connections actually exist: density = actual edges / possible edges, where the number of possible undirected edges between n nodes is n(n−1)/2.

Degree distribution

Instead of asking how connected one character is, we count how many characters share each possible degree. Hover any bar to see exactly how many characters have that degree.

Hover or tab through the bars to see exact counts.

The log–log plot makes the tail of the distribution easier to inspect. A long tail indicates that a small number of characters have substantially more connections than most characters. Whether this pattern follows a power law requires additional statistical analysis — we don't claim one here.

This unevenness is typical of real-world networks: most nodes have relatively few connections, while a small number of "hub" nodes accumulate disproportionately many.

    Methodology

    How this was actually calculated

    The Wikipedia network is directed (A → B means A's page links to B's page). For degree, density, connected components, articulation points, and shortest paths, we convert it to an undirected network (A ↔ B) — direction is only preserved for in-/out-degree analysis.

    Degree & degree sums

    For a directed graph: sum(in-degree) = number of directed edges and sum(out-degree) = number of directed edges.

    For the undirected graph: sum(degrees) = 2 × number of undirected edges, because every edge touches two nodes.

    Density

    density = m / [n(n−1)/2], where m is the number of undirected edges and n(n−1)/2 is the maximum possible number of undirected edges among n nodes.

    Connected components & isolates

    Computed on the undirected graph via breadth-first search / graph traversal (NetworkX connected_components). A node with undirected degree 0 is isolated.

    Articulation points

    Computed on the undirected graph with NetworkX articulation_points, precomputed during the analysis build (not in the browser).
